# EV Charging Analytics Dashboard

## Project Overview
This project analyzes electric vehicle (EV) charging sessions
to understand charging patterns, energy consumption, and revenue.

## Tools Used
- SQL
- Microsoft Power BI
- Data Visualization

## Dashboard Pages
1. EV Charging Overview
2. Charging Behaviour Analysis
3. Revenue Analysis
4. Key Business Insights

## Key Performance Indicators
- Total Charging Stations
- Total Energy Consumed
- Total Charging Sessions
- Average Energy per Session
- Total Revenue
- Average Revenue per Session

## Analysis
- City-wise charging activity
- Charging sessions by hour, day, and month
- Charger type analysis
- Revenue by city, month, charger type, and hour

## Project Objective
To analyze EV charging data and generate useful insights
for understanding charging demand and revenue patterns.
